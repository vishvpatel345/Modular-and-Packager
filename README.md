# Modular & Packager

A simple Python project that demonstrates how modules and packages can be used to organize different tasks in a program.

## About the Project

This project is a small multi-utility toolkit made using basic Python.

It uses Python's built-in modules such as:

- `datetime`
- `time`
- `math`
- `random`
- `uuid`

It also includes custom modules and a package to show how Python programs can be divided into different files.

## Features

The program has a simple menu with different options:

1. Display current date and time
2. Generate a random number password
3. Generate a unique UUID
4. Calculate the area of a circle
5. Calculate factorial of a number
6. Save text into a file
7. Read saved text from a file
8. Explore module functions using `dir()`
9. Run a simple countdown
10. Exit the program
